# Složka pro obnovu záloh

Sem nahraj `.json` soubor zálohy (vytvořený appkou přes "Exportovat zálohu"),
a appka ho v sekci **⚙️ Záloha dat → Obnovit z GitHub** sama najde a nabídne k obnovení.

⚠️ **Upozornění:** tento repozitář je veřejný (kvůli zdarma GitHub Pages), takže
dokud tu soubor bude ležet, bude teoreticky viditelný komukoliv na GitHubu.
Doporučuje se soubor po úspěšném obnovení dat zase smazat.
